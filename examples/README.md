# Fictional demo output

`synthetic-basic-2025.pdf` is generated from the repository's fictional CHF fixture
using the application processing entry point and synthetic reference data. It
contains Example Person, account U0000000, canton ZH, year 2025 and CHF 1,000 cash.
It contains no real broker export or person. All five pages were rendered for
visual inspection; embedded PDF417 payloads are covered by the engine tests.

The renderer comes from OpenSteuerAuszug; its attribution appears in the PDF.
The sample demonstrates output format, not tax-authority acceptance. Date/PDF
metadata can vary across regenerations. Use the test guide for an actual
destination-software import check. Personal PDFs are excluded from Git; only this
explicitly reviewed synthetic example is allowed by the publication audit.
