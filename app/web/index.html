BRIDGING THE REPORTING GAP

Different broker formats.
One Swiss workflow.

International broker reports use their own structures.
Bring supported exports into a format built for Swiss tax reporting.

Which brokers are supported?+

You can currently import annual Flex XML exports from Interactive Brokers. More broker integrations are planned. Exports from other brokers are not supported yet.

Which document should I upload?+

An Interactive Brokers Flex Query export in XML format covering the full tax year. Include account information, cash balances, positions and trades as applicable. PDF and CSV broker reports are not supported.

What needs to be in my Flex report?+

The report must run from 1 January to 31 December of the selected year. Account information must include a Swiss canton, and open positions must be dated 31 December. Use the synthetic example to see a supported export.

What does the portfolio MVP calculate?+

This version uses OpenSteuerAuszug’s minimal import mode. Securities income is omitted from the embedded XML and security valuations may be undefined. Review the output and complete matching, valuation and income calculations in a suitable tax workflow. A valid eCH schema does not establish tax-authority acceptance.

Do I need to connect a broker account?+

No. The current workflow uses file uploads from the supported broker. Direct IBKR retrieval is planned separately from support for additional brokers. This workspace never asks for your broker password or stores broker credentials.
